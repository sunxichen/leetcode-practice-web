# Triage Labels

本仓库使用本地 markdown 作为 issue tracker，五个三态角色直接写在文件顶部的 `Status:` 行里。

| 角色 | 本仓库取值 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不做 |
