# 一套记忆算法，按题集标定参数

新增面试题集时，考虑过复制一份 `sm2.ts` 独立演化，也考虑过换用 FSRS。结论是保留现有的 Anki 式 SM-2 状态机，把硬编码的常量（学习步长、间隔上限、队列编织密度）提取为按题集传入的调度参数。

记忆衰减规律不因内容是代码还是话术而改变，状态机本身与内容类型无关；真正的差异只在标定值——LeetCode 每题约 4 分钟、面试卡约 1-2 分钟，`LEARNING_STEPS_MIN` 与 `CARDS_PER_MINUTE` 的设计意图（"10 分钟后隔 2-3 题重现"）依赖这个前提，直接复用会失效。

FSRS 被否决：它需要完整的复习历史（每次评分、间隔、时间戳）来拟合参数，而当前的 `QuestionProgress` 只保存最后一次状态，没有 review log。为一个几百题的私人题库补齐历史记录并引入 FSRS，收益远小于成本。若将来要上 FSRS，第一步是先开始记录 review log。
